# Annual Leave Planner 2027

Планировщик ежегодного отпуска на 2027 год. Статическая страница: без сборки, сервера и регистрации.

- Производственный календарь РФ на 2027 год и правила ТК: одна часть от 14 дней, праздники в отпуск не входят.
- Основной и дополнительный отпуск, дейоффы.
- Подбор дат под цель: максимальный отдых, стандартный или максимальная выгода.
- Расчёт отпускных и разницы с обычной зарплатой по месяцам.
- План хранится только в вашем браузере. На другое устройство его переносят строкой или файлом.

## Запуск

Откройте `index.html` в браузере. Чтобы выложить страницу на GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.

Есть и версия одним файлом: [`dist/annual-leave-planner.html`](dist/annual-leave-planner.html). Её можно скачать и открыть без остальных файлов. После правок её пересобирают командой `python tools/build_single.py`.

## Устройство

Обычные скрипты без сборки. Подключаются по порядку в `index.html`, у всех общая глобальная область.

| Файл | Что внутри |
|---|---|
| `css/style.css` | стили, светлая и тёмная тема |
| `js/calendar.js` | производственный календарь 2027: праздники, переносы, рабочие дни |
| `js/destinations.js` | направления, сезоны, «Дома хорошо», цели подбора |
| `js/utils.js` | форматирование чисел и дат |
| `js/model.js` | состояние плана, интервалы, отдых и деньги |
| `js/render.js` | календарь, интервалы, проверки по ТК, блок денег |
| `js/storage.js` | хранение в браузере, файлы, разбор строки плана |
| `js/editor.js` | отметка дней мышью, касанием, клавишами |
| `js/generator.js` | подбор вариантов |
| `js/app.js` | кнопки, варианты, пример и запуск |
| `tools/build_single.py` | сборка версии одним файлом в `dist/` |

## Ограничения

- Это не юридическая и не финансовая консультация. Расчёты примерные: без учёта премий, изменений зарплаты и больничных.
- Правила работодателя могут отличаться: дейоффы, график отпусков, деление отпуска на части. Сверяйтесь с работодателем.
- Сезоны направлений — ориентир по погоде, а не реклама. Визы, перелёты и правила въезда проверяйте сами.
- План хранится только в вашем браузере и никуда не отправляется. Шрифты страница загружает с Google Fonts.
